# Raju Mandal — Personal Portfolio

A clean, responsive portfolio website built with **HTML, CSS, and JavaScript** — hosted freely on **GitHub Pages**.

## 🌐 Live Site

> **https://raju197.github.io/Portfolio/**

---

## ✨ Features

- 📱 Fully **mobile-responsive** — works smoothly on phones, tablets, and desktops
- 📊 **Google Analytics 4** (`G-7RCJS0CECR`) integration to track recruiter visits and engagement
- 📄 **CV Download** button with analytics event tracking
- 🎨 Professional blue theme with **Google Fonts** (Inter + Lora)
- 🔄 Smooth scroll-reveal animations and active section navigation
- 🔢 Animated statistics counter on intersection
- 🏷️ Dynamic project category filtering (*All*, *Personal*, *Professional*)
- 📬 Contact form with mailto fallback
- ⚡ Zero build step — pure HTML/CSS/JS, works offline too

## 🚀 Deploying to GitHub Pages

1. Go to your repository on GitHub: [https://github.com/raju197/Portfolio](https://github.com/raju197/Portfolio)
2. Click **Settings** → **Pages** (in the left sidebar)
3. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: `main`
   - Folder: `/ (root)`
4. Click **Save**

Your site will be live at:
```
https://raju197.github.io/Portfolio/
```
